## This Project Has Moved

Oxidite has been renamed to **Toxi** and continues development at a new repository.

**New location:** [github.com/meshackbahati/toxi](https://github.com/meshackbahati/toxi)

All future releases, issues, and documentation live there. This repository is archived and will not receive further updates.

## Why the rename?

The project was renamed from Oxidite to Toxi to better reflect its identity and direction. The framework, crates, CLI, and documentation have all been updated accordingly.

## What changed?

| Old (Oxidite) | New (Toxi) |
|---|---|
| `oxidite` | `toxi` |
| `oxidite-core` | `toxi-core` |
| `oxidite-cli` | `toxi-cli` |
| `OXIDITE_*` env vars | `TOXI_*` env vars |

## Migrating

See the [migration guide](https://github.com/meshackbahati/toxi/blob/main/docs/migration-guide.md) for upgrading from Oxidite 2.x to Toxi 3.0.
